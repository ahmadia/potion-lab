# Fizzwick's Potion Lab

A calm, screen-friendly math-practice game for kids — brew potions by answering
questions, light up jars, hatch animal friends, and collect warm little stories.

**Play:** https://ahmadia.github.io/potion-lab/

This is the second-generation lab. On first run it can **load in progress** from
the original game (same device) so no animals or stories are lost, with a Files
import as a fallback.

Single self-contained `index.html` + service worker for offline play. Add it to
your iPad Home Screen to install it as an app.
